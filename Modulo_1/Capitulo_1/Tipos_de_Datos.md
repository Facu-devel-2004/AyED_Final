# Tipos de Datos, Estructuras de Datos y TAD

En el diseño de software, los programas se componen de algoritmos que procesan datos organizados en estructuras de datos, se ditinguen los siguientes 3:

- _Tipo de Dato_:
  Define el conjunto de valores que puede tomar una variable y las operaciones aplicables sobre ellos. Se dividen en tipos primitivos, como int, char, float, bool y punteros. Y en tipos compuestos o agregados combinando tipos primitivos, como arreglos, cadenas y estructuras.

- _Estructura de Datos_:
  Es una coleccion organizada de datos que se caracteriza por la forma en que se almacenan y se relacionan sus elementos en memoria para permitir un procesamiento eficiente en tiempo y espacio.

- _Tipo Abstracto de Datos (TAD)_:
  Es un modelo matematico compuesto por una coleccion de datos y un conjunto de operaciones definidas sobre ellos, especificando de forma totalmente independiente de su implementacion. El TAD separa el que hace la estructura del como lo hace, este es el principio de las Clases en C++.
